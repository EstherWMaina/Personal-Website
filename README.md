# Esther Wanjiku Maina — Geospatial Portfolio

A professional portfolio showcasing my work and experience in **Geospatial Data Engineering, Remote Sensing, Earth Observation, GIS, and spatial data applications**.

The website highlights selected projects, technical skills, professional experience, education, certifications, and work across geospatial technology and space applications.

## 🌍 Portfolio

The portfolio is built as a lightweight static website using:

* **HTML5** — page structure and content
* **CSS3 / Tailwind CSS** — styling and responsive layouts
* **JavaScript** — interactive elements and animations
* **GitHub Pages** — website hosting

## 🖼️ Adding Images

Images are stored in the `assets/images/` directory.

### Profile photo

Place the profile image at:

```text
assets/images/portrait.jpg
```

Recommended size:

```text
800 × 1000 px
```

### Project images

Place project images in:

```text
assets/images/projects/
```

Recommended size:

```text
1600 × 1000 px
```

Use the filenames defined in the project structure, or update the corresponding image references in the HTML if you introduce new projects.

## 💻 Running Locally

The website can be opened directly by opening:

```text
index.html
```

in a web browser.

Alternatively, run it using a local static server:

```bash
npx serve .
```

Then open the local address provided by the server.

## 🚀 Deployment

The website is designed to be deployed as a static site using **GitHub Pages**.

To deploy:

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch.
5. Select `/ (root)` as the folder.
6. Save the configuration.

GitHub Pages will automatically publish the website.
